# Отрисовка окружностей с уменьшением радиуса
Программа, которая выводит на экран окружности с уменьшением радиуса

## Демонстрация работы
![Гифка работы](show.gif)

## Возможности
1. Задание начального радиуса для окружности.
![Скриншот задания радиуса](screen1.png)
2. Задание шага уменьшения радиуса окружностей.
![Скриншот задания шага](screen2.png)
3. Нажатие клавиши Enter рисует окружность с уменьшенным на один шаг радиусом.
4. Нажатие клавиши D удаляет последнюю нарисованную окружность.
5. Нажатие клавиши Esc закрывает программу.

## Реализация
Программа реализована на языке Python 3.14 с использованием библиотеки tkinter.
Среда разработки: Visual Studio Code.

## Запуск программы
1. Клонируйте репозиторий:
git clone https://github.com/ArsTerA/DrawASetOfCircles
2. Перейдите в папку с проектом:
cd DrawASetOfCircles
3. Запустите файл Lab1.py:
python Lab1.py
